Deploy in 60 Seconds

Simple Docker Compose setup or single-command bash installer with built-in TLS cert generation.

RECOMMENDED: 1-COMMAND DOCKER COMPOSE
# 1. Clone repository git clone https://github.com/theone2003a/jarvis-plus.git cd jarvis-plus # 2. Run automated setup wizard (generates TLS certs & .env) ./setup.sh # 3. Start container docker compose up -d
ALTERNATIVE: NATIVE PYTHON 3.11
cd server python3 -m venv .venv source .venv/bin/activate pip install -r ../requirements.txt # Start voice pipeline python server.py
